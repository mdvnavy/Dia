      Learn how to use DIA
      
    
      DIA turns a discovery questionnaire into a scored opportunity and three ready-to-use documents: a client profile, an opportunity analysis, and a proposal draft.
      
    
        
      
      1. Paste a completed questionnaire into the box, or choose Load sample.
        2. 
      
      2. Press the arrow (or Ctrl/⌘ + Enter) to run the intake. No API key is needed for this step.
        3. 
      
      3. Review the tier, score, and validation issues, then switch between Profile, Analysis, and Proposal.
        4. 
      
      4. Ask DIA follow-up questions. Press Enter to send and Shift + Enter for a new line. This uses the live Gemini agent.
        5. 
      
      5. Load a document into the Draft Editor to polish it into an email, then copy or download it.
        6. 
    
      
    
      Press ⌘K anywhere for the command palette, or / to jump to the input.
